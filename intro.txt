Jupyter Notebook - це інтерактивне середовище, що дозволяє виконувати код написаний на Python. 
Для створеня файлу jupyter використовується розширення .ipynb
Код можна запускати прямо в браузері.

Звичайний код написаний на пайтон, ми можемо виконати повністю весь файл.
Юпітер-ноутбук, код можна розбити на частини і виконувати частинами. Код розбивається на спецальні комірки які називаються ноутбуками.

Для запуску Юпітера використовуються дві команди:
jupyter notebook - використовується для виконання одного файлу
jupyter lab - використовується для створення середовища у якому можна виконувати декілька файлів, відкривати декілька терміналів

Сфери використання:
аналіз данних(pandas, numpy)
Data Science
Машинне навчання
Математичні розрахунки
Експерименти з Python

Де запускати Юпітер ноутбуки:
JupyterNotebook
VSCode plugins
Anaconda
Google Collab
